Test 3B.3.5 uses Census place data for U.S. city resolution and persists the study through the Cloudflare Worker and GitHub App.

Security

  • No GitHub token or GitHub App private key is stored in this browser application.
  • GitHub authentication remains in Cloudflare through the GitHub App installation.
  • City/place resolution is performed client-side using U.S. Census TIGERweb. No GitHub credential is exposed to the browser.
  • The browser sends the reviewed study to the Worker; the Worker is responsible for writing it to GitHub.
